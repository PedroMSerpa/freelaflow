# Demonstração — aproximadamente 30 segundos

Antes de gravar: iniciar o aplicativo, usar dados fictícios, fechar abas pessoais e configurar resolução de 1440 × 900 ou similar. Preparar um projeto de demonstração com pelo menos uma tarefa. Ensaiar o fluxo antes da gravação.

| Tempo   | Ação                                           | Narração sugerida                                                             |
| ------- | ---------------------------------------------- | ----------------------------------------------------------------------------- |
| 0–5 s   | Mostrar dashboard                              | “Este é o FreelaFlow, um workspace para organizar o trabalho de freelancers.” |
| 5–13 s  | Abrir projeto e mostrar tarefas, prazo e valor | “Projetos, clientes e prazos ficam conectados em um só lugar.”                |
| 13–19 s | Concluir uma tarefa e salvar                   | “Cada tarefa concluída atualiza o progresso do projeto.”                      |
| 19–25 s | Abrir Financeiro e registrar um pagamento      | “Os recebimentos atualizam o controle financeiro automaticamente.”            |
| 25–30 s | Retornar ao dashboard                          | “Menos caos, mais espaço para criar. Desenvolvido em React e TypeScript.”     |

Na apresentação em sala, explicar o problema, demonstrar criação e edição e comentar a persistência local. Não apresentar dados locais como sincronizados na nuvem nem o controle manual como processamento de pagamentos.
